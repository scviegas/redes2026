📖 Tutorial — Sockets em Python

1 · Teoria essencial

Um socket é uma das "pontas" de uma conexão de rede — o elo entre o seu programa e a placa de rede.

  • IP (127.0.0.1) = o endereço do prédio
  • Porta (5000) = o número do apartamento/ramal
  • Socket = o aparelho de telefone que você usa para falar
TCP (SOCK_STREAM)UDP (SOCK_DGRAM)
Conexão prévia✅ sim (handshake)❌ não
Garantia de entrega✅ sim❌ não
Ordem dos dados✅ garantida❌ não
Uso típicochat, web, e-mailjogos, streaming, DNS

Nosso chat usa TCP — não podemos perder mensagens!

SERVIDOR                                CLIENTE
─────────                               ─────────
socket()   ← cria o telefone            socket()   ← cria o telefone
bind()     ← escolhe IP:porta
listen()   ← vira "balcão"
accept()   ← espera o cliente  ◄─────►  connect()  ← aperta a mão 🤝
recv()     ← recebe bytes     ◄───────  sendall()  → envia bytes
sendall()  → envia bytes     ───────►  recv()     ← recebe bytes
   ... (ciclo se repete) ...
close()                                close()
⚠️ accept() e recv() são bloqueantes: o programa para naquela linha até algo acontecer. Guarde isso — é a causa do problema que o chat vai resolver!

2 · Exemplo 1 — serversock.py

serversock.py
import socket

HOST = "127.0.0.1"
PORTA = 5000

servidor = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

servidor.setsockopt(
    socket.SOL_SOCKET,
    socket.SO_REUSEADDR,
    1
)

servidor.bind((HOST, PORTA))
servidor.listen(1)

print("Servidor iniciado!")
print(f"Aguardando conexão na porta {PORTA}...")

while True:
    conexao, endereco = servidor.accept()
    print(f"Cliente conectado: {endereco}")

    with conexao:
        while True:
            dados = conexao.recv(1024)

            if not dados:
                break

            mensagem = dados.decode("utf-8")
            print("Cliente:", mensagem)

            resposta = f"Servidor recebeu: {mensagem}"
            conexao.sendall(resposta.encode("utf-8"))

    print("Cliente desconectado.")
  • HOST = "127.0.0.1" — localhost: só aceita conexões desta máquina. Para outros computadores, use "0.0.0.0".
  • AF_INET = IPv4 · SOCK_STREAM = TCP.
  • SO_REUSEADDR — evita Address already in use ao reiniciar rápido.
  • accept() devolve duas coisas: conexao (NOVO socket, exclusivo dessa conversa) e endereco.
  • if not dados: break — recv() vazio (b"") = cliente fechou a conexão.
  • with conexao: — fecha o socket automaticamente, mesmo com erro.
  • Se for Texto → encode("utf-8"); se receber Bytes → decode("utf-8"). A rede só transporta bytes!

3 · Exemplo 2 — clientesock.py

clientesock.py
import socket

HOST = "127.0.0.1"
PORTA = 5000

cliente = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

cliente.connect((HOST, PORTA))

print("Conectado ao servidor!")

while True:
    mensagem = input("Digite uma mensagem: ")

    if mensagem.lower() == "sair":
        break

    cliente.sendall(mensagem.encode("utf-8"))

    resposta = cliente.recv(1024)
    print(resposta.decode("utf-8"))

cliente.close()
print("Conexão encerrada.")
  • O cliente não usa bind/listen/accept — ele liga, não atende.
  • connect() dispara o handshake TCP (SYN → SYN+ACK → ACK).
  • Ciclo: digita → envia → recebe → mostra. Digitar sair quebra o loop.
  • Se o servidor não estiver rodando: ConnectionRefusedError.

5.1 · Por que o serversock.py NÃO serve para chat?

Experimente: rode serversock.py e conecte 2 clientes. O segundo fica travado — só será atendido quando o primeiro sair. Motivo: accept()/recv() são bloqueantes e o servidor atende um por vez.

Solução: threading (uma thread por cliente) + broadcast (repassar a todos).

                 ┌─────────── SERVIDOR ───────────┐
  Cliente A ◄───►│ while True:  accept()          │
                 │   └─► thread(A) ─► broadcast() │
  Cliente B ◄───►│   └─► thread(B) ─► broadcast() │
  Cliente C ◄───►│   └─► thread(C) ─► broadcast() │
                 └────────────────────────────────┘
🎬 Veja acontecendo: a aba 💬 Chat ao Vivo mostra exatamente essa arquitetura funcionando — conecte clientes lá e compare com o seu código!
🧵 Conceitos novos: threading.Thread(target=f, args=(a,b), daemon=True) roda a função em paralelo · a lista compartilhada usa threading.Lock() como "fila de banheiro" 🚻 · broadcast envia a mesma mensagem para todos.

servidor_chat.py

servidor_chat.py — completo
import socket
import threading

HOST = "0.0.0.0"
PORTA = 5555

clientes = []
lock = threading.Lock()


def broadcast(mensagem):
    with lock:
        destinatarios = list(clientes)
    for c in destinatarios:
        try:
            c["conexao"].sendall(mensagem.encode("utf-8"))
        except OSError:
            with lock:
                if c in clientes:
                    clientes.remove(c)


def atender(conexao, endereco):
    nome = None
    try:
        conexao.sendall("Qual é o seu nome? ".encode("utf-8"))
        nome = conexao.recv(1024).decode("utf-8").strip() or f"Anonimo-{endereco[1]}"

        with lock:
            clientes.append({"nome": nome, "conexao": conexao})

        print(f"[+] {nome} entrou ({endereco[0]}:{endereco[1]})")
        broadcast(f"*** {nome} entrou no chat ***")

        while True:
            dados = conexao.recv(1024)
            if not dados:
                break
            texto = dados.decode("utf-8")
            print(f"[{nome}] {texto}")
            broadcast(f"[{nome}] {texto}")
    except (ConnectionResetError, OSError):
        pass
    finally:
        if nome:
            with lock:
                clientes[:] = [c for c in clientes if c["conexao"] is not conexao]
            broadcast(f"*** {nome} saiu do chat ***")
            print(f"[-] {nome} desconectou")
        conexao.close()


def main():
    servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    servidor.bind((HOST, PORTA))
    servidor.listen()
    print(f"💬 Servidor de chat na porta {PORTA} — Ctrl+C encerra.")
    try:
        while True:
            conexao, endereco = servidor.accept()
            t = threading.Thread(target=atender, args=(conexao, endereco), daemon=True)
            t.start()
            print(f"[i] {endereco} conectou — thread {t.name} criada")
    except KeyboardInterrupt:
        print("\nServidor encerrado.")
    finally:
        servidor.close()


if __name__ == "__main__":
    main()

cliente_chat.py — completo
import socket
import threading

HOST = "127.0.0.1"
PORTA = 5555


def receber(cliente):
    while True:
        try:
            dados = cliente.recv(1024)
            if not dados:
                print("\n[servidor fechou a conexão]")
                break
            print("\r" + dados.decode("utf-8"))
        except OSError:
            break


def main():
    cliente = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    cliente.connect((HOST, PORTA))
    print("Conectado ao chat! Digite /sair para sair.\n")

    threading.Thread(target=receber, args=(cliente,), daemon=True).start()

    try:
        while True:
            mensagem = input()
            if mensagem.strip().lower() == "/sair":
                break
            cliente.sendall(mensagem.encode("utf-8"))
    except (KeyboardInterrupt, EOFError):
        pass
    finally:
        cliente.close()
        print("Conexão encerrada.")


if __name__ == "__main__":
    main()
